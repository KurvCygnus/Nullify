# NL-F6: Real Kotlin Styled Folded Type

* Completed(`0.4.0`)


## Description

Nullify's default folding style is actually different from Kotlin.

## Solution

A "Kotlin-style nullity markers" option places the `?`/`!` markers after the generic type arguments (e.g. `List<String!>?`, matching Kotlin) instead of before them (e.g. `List?<String!>`, the default Nullify style).
