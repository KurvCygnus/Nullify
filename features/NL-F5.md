# NL-F5: UI Config

* Completed(`0.2.0`)

* Suggested on version `0.0.2` by `Kurv Cygnus`


## Description

Config UI is not designed yet. So we need to do it ASAP.

## Solution

A settings page under `Settings → Editor → Nullify` lets users toggle nullity folding and wildcard folding independently, register custom `@Nullable`/`@NotNull` annotation types, and apply configuration changes immediately without restarting the IDE.
