NL-I2: Custom Annotation Registry Support in Folding Configuration

Resolved(`0.0.1`)

Found on version `0.0.1` by `Kurv Cygnus`

Description

There was no way to register custom nullability annotations, so user-defined or non-standard annotations were never recognized by the folding engine.

Solution Result

Users can now register custom @Nullable/@NotNull annotations and have them recognized by the folding engine.
