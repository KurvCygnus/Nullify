NL-I43: Reason Hint Does Not Appear After the Comment-Maybe-Reason Migration (NL-F21)

Open

Found on version 1.0.0 by Kurv Cygnus

Description

After applying Migrate comment to annotation reason (NL-F21) to a collapsed declaration — e.g.

// Foo
final @NotNull var carryIDBox = context.carryID;

becomes

final @NotNull("Foo") var carryIDBox = context.carryID;

— the reason hint that NL-F16 renders above collapsed Nullify folds does not appear. The hint only shows after a manual round-trip: clicking the folded text expands the fold, the fold collapses again on its own a moment later, and only then does the hint appear; a second click expands it for good. The expected behavior is that the hint shows immediately after the migration, without any manual interaction.

Root Cause

Migrating the comment changes the text inside the folded region, and the IDE rebuilds that fold region in an expanded state, which hides the hint — the hint only renders above collapsed folds. A first attempt to force the fold back collapsed programmatically was reverted: it did not make the hint appear immediately and introduced a "expand → instantly re-collapse" quirk.

Solution Result

Unresolved. The automatic re-collapse experiment (NL-F21 delivery) has been reverted; the migration itself works, but the reason hint still requires the manual expand/re-collapse round-trip before it appears.
