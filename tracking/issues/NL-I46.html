NL-I46: IndexNotReadyException When Opening Settings During Project Indexing

Resolvedon version 1.0.0

Found on version 1.0.0 by Kurv Cygnus

Description

Opening Settings → Editor → Nullify right after the IDE starts — while the project is still indexing — logged an IndexNotReadyException ("Please change caller according to com.intellij.openapi.project.IndexNotReadyException documentation"). The annotation completion was also broken during indexing: the suggestion popup produced error logs and the annotation icons could not be resolved.

Root Cause

The annotation-candidate search relies on the IDE's class index, which is unavailable while indexing is in progress. The search ran on a background thread without waiting for indexing to finish; the platform throws an exception instead of returning an empty result in that state, and the exception escaped into the IDE log.

Solution Result

Opening Settings while the project is indexing no longer produces any exception. During indexing the annotation fields simply show no suggestions and the stock annotation icon; once indexing finishes, the cache is primed and completion works as usual.
