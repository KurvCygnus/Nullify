Resolved

Found on version `0.0.1` by `Kurv Cygnus`

Description

The core processing pipeline had no structured logging across its stages, making it difficult to debug issues or trace execution flow during folding.

Solution Result

Structured trace, debug, and warning logging now covers all pipeline stages, making issues easier to diagnose.
