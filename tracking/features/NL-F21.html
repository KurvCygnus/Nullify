NL-F21: Searchable HTML Tracking Site

Completed(`1.0.0`)

Suggested on version `1.0.0` by `Kurv Cygnus`

Description

Nullify's issue (NL-I) and feature proposal (NL-F) tracking documents were published to the public tracking repository as raw Markdown files. With the number of documents growing, it became hard to browse or find a specific issue or feature. This feature adds a standalone generator that turns the tracking documents into a searchable HTML site, so users can look up any issue or feature by number or by its title.

Solution

Tracking documents are now published as a searchable HTML site: each issue and feature has its own page, and a search box on the landing page finds any document by number or by title. The published site lives under tracking/ in the public repository, with the README's demo gifs moved from docs/assets/ to assets/.
