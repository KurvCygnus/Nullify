Nullify Tracking

Nullify is an IntelliJ IDEA plugin that turns Java's verbose nullability annotations and wildcard modifiers into compact Kotlin-style syntax.

This site is its public tracking: every issue (NL-I) and feature proposal (NL-F), each with its lifecycle status.

Search by number (16, I16, NL-I16, F9) or by keywords, and use the filters to narrow by issue or feature.

Each entry's status icon carries its full status text on hover.
