NL-I45: Trailing Comment on the Declaration Line Not Recognized by the Comment-Migration Intention (NL-F21)

Resolvedon version 1.0.0

Found on version 1.0.0 by Kurv Cygnus

Description

Migrate comment to annotation reason does not fire for a trailing comment that closes the whole declaration line rather than sitting directly right of the annotation. When the comment comes after the declaration's last token — e.g.

final @NotNull var foo = "";// Assigned with a literal value.

— the intention is not offered at all. The migration only recognizes comments directly adjacent to the annotation (@NotNull // reason) or on the line above it. The expected behavior is that a comment trailing the declaration on the same physical line migrates into the annotation's reason just like any other adjacent comment.

Root Cause

The intention only looks for comments immediately next to the annotation; a comment at the end of the declaration line sits after the type and initializer, so the adjacency check never reaches it.

Solution Result

A comment that trails a single-line declaration — fields, local variables and methods alike — is now recognized: the intention fires both at the annotation and on the trailing comment itself, and the comment migrates into the annotation's reason.
