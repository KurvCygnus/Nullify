NL-I47: Modal Settings Mode Stacks Two Settings Dialogs When Clicking Welcome-Panel Section Titles

Open

Found on version 1.0.0 by Kurv Cygnus

Description

In the legacy modal Settings mode (when ide.ui.non.modal.settings.window=false), clicking one of the section-title links on the Nullify welcome panel opens a second Settings dialog stacked on top of the first one. The new dialog opens with the selected section already focused, but the original dialog remains visible underneath, requiring the user to close both windows.

Root Cause

The Nullify welcome panel uses ShowSettingsUtil.showSettingsDialog(project, ConfigurableClass) to navigate from one Configurable to another. In non-modal mode (the default since IntelliJ 2024.1), this call reuses the existing settings window by routing through SettingsVirtualFileHolder and reselecting in-place. In legacy modal mode, the same call always opens a new modal dialog, because the platform's modal code path unconditionally creates a fresh dialog and does not consult any "is a settings dialog already open" state.
