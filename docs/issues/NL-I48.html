NL-I48: Multidimensional Array Annotation Attributed to Wrong Dimension

Resolvedon version 1.0.1

Found on version 1.0.1 by Kurv Cygnus

Description

A nullability annotation written on the outer bracket of a multidimensional array is displayed on the inner array instead. For example, int @Nullable [][] was folded as Array<Array?<int>>, where the ? appears on the inner Array. Java places that annotation on the first [], which is the outermost dimension, so the folded text should mark the outer array. Multi-annotation forms with different marks on each bracket were reversed as well.

Root Cause

IntelliJ's PSI flattens array dimensions into one type element and exposes the first bracket's annotations through that element's annotation list. Nullify mapped the first bracket to the inner array and the last bracket to the outer array, reversing the JLS §9.7.4 attribution for every annotated dimension.

Solution Result

Multidimensional arrays now place annotations on the dimension where Java syntax places them. int @Nullable [][] folds to Array?<Array<int>> and int [] @Nullable [] folds to Array<Array?<int>>; forms with different marks on each bracket are attributed per bracket as well.
